NICE NMF Integration Guide

แปลง NICE .nmf เป็น WAV ด้วย .NET SaveMgr

เอกสารนี้อธิบายระบบปัจจุบันที่ใช้ `.NET SaveMgr` เป็น flow เดียวสำหรับเว็บและ integration เพื่อให้ผลลัพธ์ตรงกับ NICE Player Save WAV

.NET SaveMgr LocalPlaylist WaveController Browser WAV
ยังมีไฟล์ legacy สำหรับการทดลองเดิม แต่ flow ที่ใช้จริงคือ `.NET SaveMgr` เท่านั้น ไม่ใช้ `NmfToVox PCM_A_LAW` เป็นทางหลักแล้ว

สรุปสั้น

  • Input: ไฟล์ NICE .nmf
  • Output: PCM WAV ที่ browser เล่นได้ทันที
  • Engine ที่ใช้จริง: .NET SaveMgr
  • Runtime: C:\Program Files (x86)\NICE Systems\NICE Player Release 6
  • Bridge หลัก: Nice/tools/try_nice_player_wave_convert.ps1
  • Web server: Nice/nmf_web_player/server.py

ทำไมเปลี่ยนมาใช้ .NET SaveMgr อย่างเดียว

path เดิมที่ใช้ MediaFileConverter.NmfToVox(..., PCM_A_LAW) แล้ว decode A-law เอง มีบางไฟล์ที่ได้เสียงเงียบหรือ sample ไม่ตรงกับ manual export จาก NICE Player

flow ที่ตรงกับเมนู Save WAV ของ NICE Player คือ:

LocalPlaylist.Load(input.nmf, bUseSummedMedia: true, bIsFTFMode: false)
-> item.OutputFileName = output.wav
-> WaveController.Init(item, -1, SaveMediaType.AllTypes)
-> WaveController.Save(...)
ผลทดสอบล่าสุด: NMF 7 ไฟล์เทียบกับ manual WAV 7 ไฟล์ ได้ byte_equal true ครบ 7/7

บทบาทของ 32-bit PowerShell

ในระบบใหม่ PowerShell ไม่ใช่ converter mode แล้ว แต่เป็น x86 host process สำหรับโหลด NICE 32-bit DLL และ compile C# bridge ผ่าน Add-Type

32-bit PowerShell = x86 host process
.NET SaveMgr     = actual conversion flow

Flow การทำงาน

Browser
  -> POST /api/convert?name=<file.nmf>&engine=dotnet
  -> server.py
  -> nice_nmf_to_wav.convert_file(..., engine="dotnet")
  -> extract_wav_with_player_save(...)
  -> 32-bit PowerShell host
  -> try_nice_player_wave_convert.ps1
  -> Add-Type C# bridge
  -> NICE LocalPlaylist + WaveController
  -> output PCM WAV
  -> server ส่ง audio/wav กลับ browser

ไฟล์สำคัญ

server.py

รับ upload `.nmf`, เรียก converter, ส่ง WAV กลับพร้อม metadata ผ่าน X-NMF-* headers

nice_nmf_to_wav.py

เมื่อ engine เป็น dotnet จะเรียก extract_wav_with_player_save และรับ WAV จาก WaveController โดยตรง

try_nice_player_wave_convert.ps1

bridge หลักที่โหลด NICE DLL, สร้าง LocalPlaylist, ตั้ง output file และเรียก WaveController

Performance

ปัจจุบันยัง spawn x86 host process ต่อหนึ่ง conversion เพื่อ isolate state ของ NICE runtime:

request -> start 32-bit host -> load NICE DLL -> convert -> exit

สำหรับ production ควรจำกัด concurrent conversion, ตั้ง timeout, cleanup temp file และ log convert time ทุกไฟล์ ถ้าโหลดสูงมากค่อยพิจารณา x86 worker/service ที่โหลด DLL ค้างไว้

การตรวจสอบ output

  • WAV เล่นได้
  • sample rate = 8000 Hz
  • channels = 1
  • bits = 16
  • duration ตรงกับ NICE Player manual save
  • waveform ไม่เงียบ

Error ที่พบบ่อย

NICE runtime ไม่ครบ

NICE Player runtime is not ready
missing DLL...

Checklist ก่อนนำขึ้นระบบ

  • ติดตั้ง NICE Player Release 6 บน server
  • GET /api/health ต้องได้ ok: true
  • dotnetReady: true
  • required DLL ทุกตัวเป็น exists: true
  • ทดสอบ convert ด้วยไฟล์ตัวอย่างจริง
  • ตรวจ X-NMF-duration, X-NMF-engine, X-NMF-convert-ms
  • จำกัด concurrent conversion
  • ตั้ง cleanup temp file และเก็บ log error
